# Bone Fracture Detection
3rd Year College Project

### Note:
The manual folder contains work that detects the location and severity level of bone fractures in a given X-ray image.

### How to run:
* Clone the repository: `git clone https://github.com/Pruthviraj42004/Bone-fracture.git`
* Head to the root folder: `cd Bone-fracture`
* Install requirements: `pip install -r requirements.txt`
* Head to the `manual` folder: `cd manual`
* Run `main.py`: `python main.py`

###
To test on different images, alter the corresponding variables inside `manual/main.py`.
